Apply the `status` skill.

1. State the goal of this session in one sentence, taken from the user's opening ask —
   the outcome, not the tasks. Note a pivot in half a line if there was one.
2. Check the real state before listing: `git status`, `git log --oneline`, the files,
   the last command's output. Your earlier messages don't count as evidence.
3. List it: **Done** / **In progress** / **Not started** / **Dropped** / **Unverified**,
   one plain-English line each, dropping empty statuses.
4. Close with one line on where that leaves the goal.

Report and stop — no question, no options, no new work. If the args name a narrower
scope, limit the list to it.
